# What About MOSDAC?

**Yes, you can use MOSDAC**, especially because your problem is India-focused.

MOSDAC provides meteorological/satellite datasets and has an API/download mechanism. Some open data can be accessed anonymously, while downloading other datasets requires a registered account. ([MosDAC][1])

For example, MOSDAC lists rainfall products such as INSAT-3D rainfall data, with the dataset marked **“Not Priced Products.”** ([MosDAC][5])

So:

**Cost:** Free for applicable datasets
**Account:** Depends on dataset
**Important:** Follow the individual dataset's usage/attribution restrictions.

## One important issue

For **PS 26079**, the hardest part isn't creating the React website or FastAPI.

It is obtaining a sufficiently good **historical NWP forecast + matching observation dataset**.

You need:

```text
Forecast issued on Day 0
        ↓
Prediction for Day 1
        ↓
Actual Day 1 observation

Prediction for Day 2
        ↓
Actual Day 2 observation

...

Prediction for Day 10
        ↓
Actual Day 10 observation
```

Without that pairing, you cannot properly train a **forecast bust detector**.

So I would **not** spend your time buying any weather API.
